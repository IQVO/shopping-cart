REST contract of the shopping-cart bounded context of the digital storefront, derived from storefront/model/model.yaml (contexts[shopping-cart].rest) and the FINAL model-gap decisions (H1-H6 and checkout H10). The cart holds a shopper's intent: lines, destination postal prefix, the delivery quote delivery-promise returned for the cart (per shipment group, with offers and expiry), the shopper's tier selection per group, and a labelled, non-binding estimate (effective prices + selected tier charges + tax band) so the total cost is visible up front. Without a destination the estimate shows the item subtotal only and estimateComplete is false. One line per item; adding an existing item merges quantities. Any line or destination change clears the quote and the selections. Errors are RFC 9457 problem details (application/problem+json) whose type is /problems/&lt;slug&gt;; shared types are not-found (404), illegal-transition (409), concurrent-update (409) and validation-failed (422), plus one kebab-case slug per Err of the model. Every write takes an Idempotency-Key header. No authentication; shopperId is optional (guest-first).
